**读回边界（2026-10-04 独立集成复审 P1-3 修复）**：阶段指针的 `section` 是**哈希绑定定位**（materialSection 口径：标题行+全部后代，识别围栏/闭合 `#`/行首缩进），**不等于** `read_design`/`read_plan` 的 `section` 参数（`documents.buildSectionIndex` 口径，父节不含后代）。故不把指针的 `section` 转传那两个工具；`required_reads` 里另透传**派生** `range`（该章节当前起止行，非指针 JSON 键、不保存行号，随当前解析现算），执行方按 `path`+`range` 读回标题与整棵子树。
