## 三视图（架构 / 数据流 / 导图）

### §3.2 三视图定性（已决 2026-09-19，口径以代码为准）

- 三视图**共享同一份静态依赖数据**，节点与边来自同一解析结果。
- **模块方框图**：答「项目由哪些组成部分、各是什么状态」；画全量依赖边，箭头=依赖方向，边中性色。
- **数据流向图**：答「数据从哪来、到哪去、谁依赖谁」；在同一份边上取子集（剔自环 → 互惠对归并 → 箭头翻转为「提供者→消费者」），按流向角色着色。
- **思维导图**：答「层级结构一览，适合快速总览与折叠」；不画依赖边，画父子层级边。
- 三视图均随代码解析结果实时更新（文件监听 + 自动重算），无需启动项目。

### 数据流向图口径（已决）

- 定义为**同一份静态依赖数据的「方向取向」渲染**，不引入运行时数据流。
- **不做运行时数据流**：不要求把项目跑起来采集内存数据；理由为运行时采集对前端项目不可行、侵入性强、准确性差，且会导致与方框图数据源分家（违背「唯一数据源」约束）。
- 文档表述统一采用上述代码口径，不再使用「同一份数据的两种渲染」这类易被误读为「两图内容相同」的措辞。

### 补全层

- 补全层（`chat:` 节点）为**唯一合并点**，三视图共享该机制。
- 当前补全层内容为空（0 节点 0 边），机制已就绪，未使用。
