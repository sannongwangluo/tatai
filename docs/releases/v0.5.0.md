塔台 v0.5.0（2026-10-13）—— **运行诊断与工作区／交付候选隔离版**。**相比 v0.4.0 有功能性新增、接口面变化；界面结构与数据格式向后兼容。**

## 新增了什么（以下均已交付代码与服务）

### 1. 运行诊断页与运行健康只读读口（V09-69、V09-70）

- 辅助入口「维护诊断」组新增**只读运行诊断页**：用大白话看服务、队列、近期故障与实测耗时，缺项如实标「没测到」、不编数，可导出**脱敏报告**；主工作面只在有可行动异常时给**一条**运行提示。
- 页面可见时**每约 5 秒**轻量监看，连接失败只做**有上限的只读重连**（成功即停本轮重试、恢复正常监看），切项目中止旧回包。
- **只读**：不自动重启后端、不拉起写服务、不改代码/账本、不放松门禁，导出与「重试」同样只读。读失败语义如实——超时不等于服务已死，失败把当前状态落「未知」、**不用上一次的绿代替**。
- Agent 侧**不新增工具名**：既有 `doctor` 默认附 `runtime` 段（读宿主同一只读读口、不本地重算），`runtime_only:true` 只取轻量运行诊断，不启动服务、不触发自愈。运行健康与交付验收**分开**。

### 2. 接续与同步读取默认 10 秒预算（V09-37 返工收敛）

- 接续入口与同步只读读口默认 **10 秒**预算；同一请求内共享同一份账本快照与派生事实、减少重复读盘，文件观测收敛到逐清单剩余预算内。
- 对成功但非法／不完整的响应报明确读失败、**不回退本地重算**。
- **如实限制**：这是预算与去重，不是「性能全面解决」——开发版单笔接续仍约 **7.5 秒**、稳定 p95 未证明；三笔重接续并发曾出现一次 10 秒超时，该失败**原样保留**，不能把单笔场景通过说成并发已修复。

### 3. 工作区与交付候选隔离、本地 Git 收尾（V09-63…V09-67）

- 新增 MCP `manage_workspace`：项目工作目录与交付候选的**统一入口**（`read`／`list` 只读，其余操作经唯一写口；主开发目录由 `<project>:main` 派生、不重复保存）。写口语义上拒绝错目标与对冻结候选的改写（**语义校验，不冒充 OS 沙箱**）。同一判据 HTTP 读口：`GET /api/projects/:id/workspaces`。
- 交付候选可**冻结并绑定构建输入身份**（复用 §6.10 的能力，不另算），试用提升由宿主**实测真实产物**后判定；回收后能从提交/既有保管处还原的不判失效。
- 新增 MCP `finalize_local_commit`：技术验证与独立审查通过、且持有有效任务授权时，由**唯一宿主**把**本次受验内容**做**本地提交**——内容等于受验输入、不空提交、**不 `push`**、不代签用户接受。请求**不得自带**授权/通过布尔。

### 4. 交付总览的版本一致与集成/审查读数（V09-62 扩展、V09-68）

- 交付总览顶部可切换「读哪个版本」：**当前试用候选**或**开发中**；本批受影响证据可按候选版本续验。
- `feature_ledger.delivery`（含 `integration` 组合流程验证）与逐项 `agent_review` 为**同源只读扩展**；旧宿主缺字段应报未知，不拿其它绿状态代替，**不新增完成台账**。
- 实现读数修正：缺登记与部分提交**不误报**「未实现／未开始」。

## 升级建议（从旧版覆盖安装）

- 装新版＝从 [Releases](https://github.com/sannongwangluo/tatai/releases) 下一个新包**覆盖安装**，没有自动更新。
- **升级前先正常退出塔台**：正常关窗通常会回收它启动的后端并释放 8787 端口，但**桌面壳进程本身可能滞留不退**（本版隔离实测：后端已回收、端口已释放，壳窗口 15 秒内未退出），请以**实际状态**为准。若安装器仍提示进程占用，先核实是否有残留（或该端口被别的进程占着），确认后再继续，**不要无差别结束 node 进程**（别的 Agent 客户端可能正用着它）；若需强制处理，只结束该滞留壳及其自有后端子树（不误杀其他 Agent 客户端，已核实）。
- **升级前建议先备份两处**：全局数据目录（`~/.tatai` 或你的 `TATAI_HOME`）与每个被纳管项目根下的 `.工作台/`。覆盖安装与卸载都**不删用户数据**（数据不在安装目录里，安装目录运行期只读）。
- **旧 MCP 连接需重连**（见上「变更」）：升级后当前会话要用上新工具，需重连塔台 MCP。
- 本版**未变更锁文件**（`pnpm-lock.yaml` 未动）。
